# DigSolutions — Implementation Log

This folder is the running memory of the build. Every meaningful decision, install, blocker, and lesson learned goes here so future sessions (human or agent) can pick up cleanly.

## Conventions

- One file per session/topic: `YYYY-MM-DD-<topic>.md`
- `lessons.md` — durable lessons that survive across sessions
- `stack.md` — current tech stack + versions
- `decisions.md` — architectural decisions (ADR-lite)
- `blockers.md` — open issues to revisit
